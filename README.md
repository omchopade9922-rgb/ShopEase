# ShopEase

A simple online shopping website built using HTML, CSS and JavaScript. ShopEase provides a clean shopping interface where users can browse products, add items to their cart and view their order summary.

## Features

- Display products dynamically
- Add products to cart
- Increase and decrease product quantity
- Remove items from cart
- Automatic price calculation
- Delivery charge calculation
- Cart data saved using LocalStorage
- Checkout order summary preview
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Use

1. Browse the available products.
2. Click Add to Cart to add a product.
3. Open the cart to manage quantities.
4. Review the total price.
5. Click Proceed to Checkout to view the order summary.

## Delivery Rule

A delivery charge of ₹40 is applied when the cart subtotal is below ₹500. Orders of ₹500 or more have free delivery.

## Disclaimer

This project is created for learning and demonstration purposes. No real payments are processed.
